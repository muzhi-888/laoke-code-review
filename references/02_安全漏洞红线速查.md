# 安全漏洞红线速查

本文件是审查时的"安全快查表"。命中任何一条，原则上应作为 HIGH / CRITICAL 退回。对应本 Skill 的 `review_scan.py` 已能自动识别其中大多数静态特征。

---

## 一、注入类（最高频、最致命）

### 1. SQL 注入
**危险写法**：把用户输入拼进 SQL 字符串。
```python
# ❌
sql = "SELECT * FROM users WHERE name = '" + name + "'"
cursor.execute(sql)
```
**正确写法**：参数化查询。
```python
# ✅
cursor.execute("SELECT * FROM users WHERE name = %s", (name,))
```
审查要点：凡见到 `execute(` / `raw(` / `query(` 且参数来自字符串拼接，直接判 CRITICAL。ORM 也要查是否用了 `.raw()` 或字符串 f-string。

### 2. 命令注入
`os.system(user_input)`、`subprocess` 用 `shell=True` 拼接变量，都危险。审查要点：优先 `subprocess.run([...], shell=False)`，禁止拼接外部输入进 shell。

### 3. 反序列化注入
Python `pickle.loads(untrusted)`、Java 原生反序列化、PHP `unserialize` 都能执行任意代码。审查要点：不可信来源的数据不要用这些反序列化。

## 二、硬编码密钥（数据泄露头号来源）

**危险写法**：
```python
password = "s3cr3t123"
api_key = "ak_live_8f2c91"
token = "tk_9921"
```
审查要点：任何 `password / api_key / secret / token / private_key / credential` 赋值为字符串字面量，判 CRITICAL。
**正确做法**：
- 运行时从环境变量读：`os.environ["API_KEY"]`
- 或用密钥管理服务（Vault / 云 KMS / 配置中心）
- 配置文件只放占位，真实值走 CI/CD 注入
- `.env` 文件必须进 `.gitignore`，且永不提交

> 扫描器对 `key = "..."` 形式敏感。注意：连"看起来像测试密钥"的字符串也可能被扫出——这故意保持严格，因为测试密钥常不小心用进生产。

## 三、弱加密与哈希

**危险写法**：
```python
hashlib.md5(password.encode()).hexdigest()   # 弱，且未加盐
```
审查要点：密码存储禁用 MD5 / SHA1 / 无盐哈希。判 HIGH。
**正确做法**：用 `bcrypt` / `argon2` / `scrypt`（自带加盐）。非密码摘要可用 SHA-256。

---

## 四、认证与授权（越权）

审查要点：
- 敏感操作是否校验了"当前用户是否有权做这件事"，而不只是"是否登录"？
- 前端隐藏按钮 ≠ 后端授权；后端每个入口都要查权限。
- 改资源时是否校验了资源归属（IDOR 漏洞：A 用户改 B 用户的订单）？
- 会话 / Token 是否有过期与失效机制？登出是否真的失效？

---

## 五、eval / exec（代码执行）

**危险写法**：`eval(user_input)`、`exec(template)`。
审查要点：判 HIGH。任何把外部可控字符串当代码执行都是注入。需要"动态"时改用安全映射 / 配置驱动 / 沙箱。

---

## 六、调试残留

**危险写法**：`import pdb`、`breakpoint()`、写死的 `print` 调试、`console.log` 大量残留。
审查要点：提交前必须清掉调试器调用；`print` 改 `logging`。

---

## 七、异常处理吞错

**危险写法**：
```python
try:
    do_something()
except:        # 裸 except
    pass        # 吞掉一切
```
审查要点：裸 `except:` 判 HIGH——它会连 `KeyboardInterrupt` / `SystemExit` 都吞掉，且让真实错误彻底消失。至少 `except Exception as e:` 并日志记录；更优是捕获具体异常。

---

## 速查记忆

> **拼字符串进 SQL / 命令 = 死**
> **密钥写源码里 = 死**
> **eval 外部输入 = 死**
> **裸 except 吞异常 = 死**
> **权限只查登录不查归属 = 死**

五条全中一条，安全维度不过关。
